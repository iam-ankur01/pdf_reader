# PDF Question Answering WebApp

📄 A Streamlit web app that lets you upload a PDF and ask questions about its content using a local Flan-T5 LLM and embeddings.

## Features
- Upload any PDF
- Split PDF into chunks for better QA
- Use HuggingFace embeddings (`all-MiniLM-L6-v2`)
- Ask questions and get answers from the PDF content
